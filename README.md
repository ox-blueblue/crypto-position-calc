# 加密货币仓位计算器

专业的加密货币仓位管理助手，帮助交易者科学计算仓位大小。

## 功能特点

- 支持 Binance、OKX、Bitget、Bybit、Hyperliquid 五大交易所
- 自动识别现货/合约手续费率
- 完整的仓位计算逻辑
- 全面的风险检查
- 可自定义手续费率

## 使用方法

### 1. 填写交易参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 交易所 | 选择交易平台 | Binance |
| 标的/币种 | 交易品种（可选） | - |
| 账户总额 | 账户总资金（USDT） | 1000 |
| 开仓价格 | 入场价格 | - |
| 止损价格 | 止损价位 | - |
| 止盈价格 | 止盈价位 | - |
| 杠杆倍数 | 1=现货 | 1 |
| 止损亏损比例 | 止损后亏本金的百分比 | 1% |

### 2. 点击计算

填写完必填参数后，点击"计算仓位"按钮即可获得结果。

### 3. 查看结果

计算结果包含：
- 方向（做多/做空）
- 止损亏损金额
- 预期盈利
- 盈亏比
- 开仓数量
- 实际仓位
- 保证金
- 开仓/止损/止盈价格
- 手续费相关信息

### 4. 费率设置

点击右上角 ⚙️ 按钮可自定义各交易所的手续费率。

## 计算逻辑

### 第1步：判断方向
- 止损价格 < 开仓价格 → 做多（Long）
- 止损价格 > 开仓价格 → 做空（Short）

### 第2步：计算止损距离
- 做多：止损距离 = (开仓价格 - 止损价格) ÷ 开仓价格
- 做空：止损距离 = (止损价格 - 开仓价格) ÷ 开仓价格

### 第3步：计算最大亏损金额
```
最大亏损金额 = 账户总额 × 止损亏损比例
```

### 第4步：手续费修正
```
手续费成本 = 手续费率 × 2（开仓+平仓）
实际止损成本 = 止损距离 + 手续费成本
```

### 第5步：计算名义仓位
```
名义仓位 = 最大亏损金额 ÷ 实际止损成本
```

### 第6步：计算保证金
```
保证金 = 名义仓位 ÷ 杠杆倍数
```

### 第7步：计算开仓数量
```
开仓数量 = 名义仓位 ÷ 开仓价格
```

### 第8步：计算止盈距离
- 做多：止盈距离 = (止盈价格 - 开仓价格) ÷ 开仓价格
- 做空：止盈距离 = (开仓价格 - 止盈价格) ÷ 开仓价格

### 第9步：计算预期盈利
```
预期盈利 = 名义仓位 × 止盈距离 - 名义仓位 × 手续费率 × 2
```

### 第10步：计算盈亏比
```
盈亏比 = 预期盈利 ÷ 最大亏损金额
```

## 风险检查

系统会自动检查以下风险：

### ❌ 错误（无法开仓）
1. **保证金超余额** - 保证金超出账户余额
2. **盈亏比不足1:1** - 预期收益不覆盖风险
3. **止损距离不足** - 止损距离小于手续费成本
4. **方向错误** - 止损方向与开仓方向矛盾

### ⚠️ 警告（建议调整）
1. **仓位偏重** - 保证金占比超30%
2. **盈亏比偏低** - 建议3:1以上更安全
3. **高杠杆风险** - 杠杆超过20倍

---

## 注意事项

1. **方向判断**：做多时止损价必须低于开仓价，做空时止损价必须高于开仓价
2. **盈亏比建议**：建议盈亏比达到3:1以上，低于1:1无法覆盖风险
3. **高杠杆风险**：杠杆越高，强平风险越大，请谨慎使用
4. **手续费影响**：实际止损成本 = 止损距离 + 双向手续费
5. **费率设置**：不同交易所、不同账户等级费率不同，可根据实际情况调整
